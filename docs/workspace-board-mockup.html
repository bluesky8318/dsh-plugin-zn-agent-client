  • 5状态点：运行中（agent 正在跑）/ 等待你（需要确认或提问）/ 空闲 / 已归档。数据来自会话列表元数据（只读 projcache + 客户端会话状态）。

  • 8行内容：agent 徽标（Q=qoder / K=kimi / C=claude）+ CLI 会话首条消息标题 + agent 名 + 更新时间 + PTY 状态。
  • 9恢复：复用现有 CLI Agent 视图的 resume 流程（打开一个新 DSH 会话并恢复该 CLI 会话，PTY 续接）；数据来自插件现有的按工作区历史读取，不读不改任何 DSH 会话日志。

④ 数据与安全边界

  • ✓只读数据源：~/.dsh/storages/workspace.json（工作区↔会话归属）+ session_projcache/*.json（标题/时间）——workspace-insight 已验证的只读配方。
  • ✓零写入：不写会话日志、不写 turn 事件、不改会话标题、不改侧栏会话区。所有写操作（归档/新建/打开）都走 DSH 官方 client API。
  • ✓CLI 会话：沿用插件现有历史读取（首次 64KB 扫描 + 按工作区过滤），只增显示，不动数据。
